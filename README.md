# ระบบแจ้งซ่อม (Repair Management System)

ระบบรับแจ้งซ่อมและติดตามงานซ่อมผ่านเว็บ พัฒนาบน [Now.js](https://github.com/goragodwiriya/nowjs) (ฝั่ง front-end) และ Kotchasan (ฝั่ง PHP) รองรับการรับงาน มอบหมายช่าง ติดตามสถานะ พิมพ์ใบรับซ่อม และแจ้งเตือนลูกค้า

## ฟีเจอร์

- **งานซ่อม** – รับงาน สร้างเลขที่งานอัตโนมัติ (ค่าเริ่มต้น `JOB0001`) แก้ไขรายละเอียด และเก็บประวัติของแต่ละงาน
- **สถานะงานซ่อม** – กำหนดสถานะได้เอง โดยงานใหม่จะได้สถานะแรกที่ตั้งไว้อัตโนมัติ
- **ลูกค้าและอุปกรณ์** – เลือกข้อมูลเดิมซ้ำได้ด้วยระบบ autocomplete
- **ติดตามงาน** – ลูกค้าตรวจสอบความคืบหน้าได้จากเลขที่งาน
- **ใบรับซ่อม** – พิมพ์ใบรับซ่อมพร้อม QR Code
- **แดชบอร์ดและส่งออกข้อมูล** – สรุปภาพรวมงานซ่อมและส่งออกข้อมูล
- **การแจ้งเตือน** – รองรับ LINE, Telegram และ SMS (Thaibluksms)
- **ผู้ใช้และสิทธิ์** – กำหนดสิทธิ์ตามบทบาท (`can_received_repair`, `can_repair`, `can_config`) รองรับการเข้าสู่ระบบด้วยโซเชียลและการจัดการโปรไฟล์
- **หลายภาษา** – ภาษาไทยและอังกฤษ แก้ไขได้จากหน้าผู้ดูแล
- **ติดตั้งเป็นแอปได้ (PWA)** – มี web app manifest และ service worker
- **ตัวติดตั้ง** – ติดตั้งผ่านเว็บ และมีสคริปต์ CLI สำหรับติดตั้งใหม่และอัปเกรด

## ความต้องการของระบบ

- PHP 7.4 ขึ้นไป
- MySQL 5.5.3+ หรือ MariaDB 5.5+ (utf8mb4)
- Apache ที่เปิด `mod_rewrite` (มีไฟล์ `.htaccess` มาให้แล้ว)
- Node.js 18+ เฉพาะกรณีต้องการ build ไฟล์ front-end ใหม่ (ไม่บังคับ)

## การติดตั้ง

1. คัดลอกโปรเจกต์ไปไว้ใน document root ของเว็บเซิร์ฟเวอร์
2. ตั้งสิทธิ์ให้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์ `settings/` และ `datas/` ได้
3. เปิด `http://your-host/install/` ในเบราว์เซอร์ แล้วทำตามขั้นตอน (ตรวจสอบระบบ → ตั้งค่าฐานข้อมูล → สร้างผู้ดูแล)
4. เมื่อติดตั้งเสร็จ ให้ลบหรือป้องกันโฟลเดอร์ `install/`

### ติดตั้งผ่านบรรทัดคำสั่ง

```bash
# ติดตั้งใหม่ลงฐานข้อมูลเปล่า
php install/cli-fresh.php <dbname> [prefix] [--admin=<user>] [--password=<pass>]

# อัปเกรดระบบที่ติดตั้งอยู่แล้ว
php install/cli-upgrade.php <dbname> [prefix]
```

> ควรเปลี่ยนรหัสผ่านผู้ดูแลทันทีหลังติดตั้ง

## การตั้งค่า

ค่าตั้งค่าของเว็บอยู่ที่ `settings/config.php` และข้อมูลเชื่อมต่อฐานข้อมูลอยู่ที่ `settings/database.php` ทั้งสองไฟล์สร้างโดยตัวติดตั้งและไม่ถูกเก็บใน version control ค่าที่เกี่ยวกับงานซ่อม:

| คีย์ | คำอธิบาย | ค่าเริ่มต้น |
| --- | --- | --- |
| `repair_first_status` | ID ของสถานะที่ใช้กับงานใหม่ | `1` |
| `repair_prefix` | คำนำหน้าเลขที่งาน | _(ว่าง)_ |
| `repair_job_no` | รูปแบบเลขที่งาน (รูปแบบ `sprintf`) | `JOB%04d` |

ค่าของ LINE, Telegram และ SMS ตั้งได้จากหน้าตั้งค่าของผู้ดูแล

## โครงสร้างโปรเจกต์

```
Gcms/             คลาสสนับสนุนของแอป
Kotchasan/        PHP framework
Now/              Now.js front-end framework (ซอร์สและ dist/)
modules/
  index/          ผู้ใช้ สิทธิ์ ภาษา การตั้งค่า แดชบอร์ด
  repair/         งานซ่อม สถานะ ลูกค้า อุปกรณ์ ใบรับซ่อม
  download/       ดาวน์โหลดไฟล์
  export/         ส่งออกข้อมูล
  timeline/       ไทม์ไลน์กิจกรรม
install/          ตัวติดตั้ง (เว็บและ CLI) สคีมา SQL และสคริปต์อัปเกรด
language/         ไฟล์แปลภาษา (th, en)
line/ telegram/   webhook endpoint
Thaibluksms/      ไคลเอนต์ SMS gateway
```

## การพัฒนา front-end

ไฟล์ที่ build แล้วใน `Now/dist` พร้อมใช้งาน หากต้องการ build ใหม่:

```bash
npm install
npm run build
```

## ข้อควรระวังด้านความปลอดภัย

- ห้าม commit โฟลเดอร์ `settings/` และ `datas/` เพราะมีรหัสผ่านและไฟล์ที่ผู้ใช้อัปโหลด
- ควรให้บริการผ่าน HTTPS (จำเป็นสำหรับการติดตั้ง PWA และ service worker)
- ลบโฟลเดอร์ `install/` ออกจากเซิร์ฟเวอร์จริง
